# Практическая №6 — JSON и сессии

Запуск: `php -S localhost:8006 -t public`  
Открыть: http://localhost:8006

`data/notes.json` — файловое хранилище заметок, `users.json` — пользователи.  
`session_start()` и `$_SESSION` сохраняют текущего пользователя между запросами.  
`public/index.php` обрабатывает POST и готовит данные, `templates/list.php` выводит HTML.  
После добавления — redirect, чтобы обновление не повторяло POST.  
Ограничения: JSON не подходит для одновременной записи большим числом пользователей; выбор пользователя — учебный, без пароля.
